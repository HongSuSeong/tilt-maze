# 틸트 미로 5차: 4–10번 세계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 세계 하나 = 아래 다섯 단계, 끝나면 main에 합치고 배포.

**Spec:** `docs/superpowers/specs/2026-11-09-tilt-maze-design.md` ("4–10번 세계 세부")

## 세계마다 같은 순서 (불의 세계 때와 같음)
1. 물리 시험 → 구현 (`src/physics.js`): 새 장치와 새 원소의 반응, 이벤트 이름
2. 원소와 한 판 시험 → 구현 (`src/elements.js`, `src/run.js`): 원소 추가, 실패 이유
3. 검사 시험 → 구현 (`src/levels/validate.js`): kit에 원소가 없으면 막히는 곳
4. 단계 10개 (`src/levels/worldN.js`), 시험: 쉬움·보통 20개 검사 통과, 모두 새 원소가 필요
5. 3D·화면 (`src/render3d.js`, `src/ui.js`, `src/text.js`, `src/main.js`), 캡처, 연기 시험 한 줄, 배포

## 장치 데이터 (판 단위)
- 4: `slick: rect[]`(구름 저항 ×0.1), `deep: rect[]`(중심 들어가면 `drown`, 얼음 두르고 닿으면 `freeze {deep}` → 그 자리가 빙판)
- 5: 벽 `fence`(닿으면 `shock`), `switches: {x, y, open: wallIndex[]}`(전기 두르고 4.2+2.5 안 → `power {sw}`, 열 벽들 state.broken), `zaps: rect[]`(2초 켜짐/꺼짐, 시작은 켜짐), `enemies: {x, y, speed}`(기본 속도 28)
- 6: 벽 `thick`(돌 두르고 수직 속도 > 60이면 `break`), 돌 두르면 `crack`도 > 60이면 깨짐, 돌 두르고 `deep`에 중심 → `drown`(얼어 있어도 아님)
- 7: `winds: {x, y, w, h, dx, dy}`(가속 dx,dy, 가스면 ×3), `gaps: rect[]`(중심 들어가면 `fall`, 가스면 괜찮음), 가스 + 불기둥/횃불 → `boom`(반지름 18 안의 벽 모두 state.broken, 공을 반대로 400 속도)
